# Student Management System

## About the Project
A simple C++ console application that manages student records.
This project was built for learning and practicing C++ programming.

## Features
- Add a new student.
- Display all students.
- Search for a student by ID.
- Edit student information.
- Delete a student.
- Navigate through a menu.

## Student Information
Each student has:
- ID
- Name
- Grade

## Technologies
- C++
- Standard Template Library (STL)
- Visual Studio

## Concepts Used
- Structures (struct)
- Vectors
- Loops
- Conditional statements
- Switch statements
- Console input and output

## How to Run
1. Open the project in Visual Studio.
2. Use a C++ Console App project.
3. Add the source code from `main.cpp`.
4. Build and run the program.

## Limitations
Student records are stored in memory only.
All records are lost when the program closes.

## Future Improvements
